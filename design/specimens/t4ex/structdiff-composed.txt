What it is: Structural diff of Java sources that parses Java source into a tree of declared elements and compares two versions of a file, reporting which elements were added, removed or changed [r2, r3, r4]

StructuralDiffBuilder:
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) classifies a node as added when the old element is null and the new element is non-null [k1, k13]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) classifies a node as deleted when the old element is non-null and the new element is null [k2, k14]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) classifies a node as modified when both elements are present with different content [k3, k16]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) classifies a node as unchanged when both elements are present with equal content [k4, k15]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) takes the node's type from the new element when present, else from the old element [k5, k6, k22]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) takes the node's id from the new element when present, else from the old element [k7, k8, k23]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) aligns children by id, so a child present only in the new element appears as an added child node [k17]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) aligns children by id, so a child present only in the old element appears as a deleted child node [k18]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) aligns children by id, so a child present in both elements with different content appears as a modified child node [k19]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) aligns children by id, so a child present in both elements with identical content appears as an unchanged child node [k20]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) sorts the children list of a diff node by id, giving deterministic ordering regardless of input order [k21]
- StructuralDiffBuilder.diff(ParsedElement, ParsedElement) yields a root that is unchanged and whose children are all unchanged when the diff of two identical whole trees is computed [k24]
