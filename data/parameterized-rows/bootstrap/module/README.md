# parameterized-rows

A project's own test run read as evidence, extracted from Autobuilder. SurefireReports reads the per-class
XML reports a JVM test run writes into a TestRunReport -- totals, the failing tests with their messages, and
each class's per-test outcomes. TestRunPromptBlock renders a report for a reader within a character budget.
TestAssertionVocabulary names the test annotations and assertion calls the project recognises. Pure: files
and values in, values out.
