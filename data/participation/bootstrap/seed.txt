  An existing project, adopted. It was written by someone else and it already builds. In its own
  words, from its README:

    "participation -- Per-role participation windows and the request records they are built from.
    A window says that a role participates, with a boost, for a stated number of cycles. Windows and
    requests are immutable: granting, raising, shrinking and ageing one returns a new value, and a
    value past its horizon or below its threshold reports itself expired."

  It is a library: it has no main method, serves nothing and prints nothing. It is used by creating
  its values and calling their methods. These are its entry points:

    ParticipationWindow.of(role, boost, decayEquivalent, source)   ParticipationWindows.grant(window)
    ParticipationWindow.grant(other)                               ParticipationWindows.revoke(role)
    ParticipationWindow.shrink()                                   ParticipationWindows.tick()
    ParticipationWindow.expired()                                  ParticipationWindows.boost(role)
    ChannelRequest.horizonFromDecay(strength, decayPerCycle)       ChannelRequest.raise(other)
    ChannelRequest.expired()                                       SignalType.of(name)

  OBJECTIVE: every entry point above is covered by a test in the project's own test suite, and the
  whole suite passes.

  Work inside the project as it is. Keep its packages, its classes, its naming and its test
  framework choice. Add tests under src/test/java. DO NOT modify anything under src/main/java: not
  the formatting, not the signatures, not the logic. If a test you wrote does not pass, the test is
  what is wrong.

  A test must assert what the entry point actually returns. Do not assume a result: build the values
  it needs inside the test itself, call it, observe the answer, and assert that. If the behaviour
  looks wrong to you, still assert the behaviour it has, and say what looked wrong in the test name
  or a comment. Deciding whether that behaviour should change is not part of this objective.
