# receiver-questions

A stuck build's failure signature read as a question about the code, answered from the code itself,
extracted from Autobuilder. StuckQuestions answers what a type declares, how a record is constructed,
which overloads a method has, and where an unresolved name is declared -- from the project's sources and,
for a class name, from the running JDK. DeclaredMembers lists a type's callable members. Pure: source text
in, values out.
