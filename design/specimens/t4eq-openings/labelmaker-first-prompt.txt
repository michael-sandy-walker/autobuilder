What it is: Shipping-label codes for parcels: a zone from the postcode, a running number, and a check character. [r2]
How it is used: library-style -- exercised inside the same process, by a test that calls it. Exercised here through: Zone.of, Labeler.checkChar, Labeler.next, Labeler.isValid.

Zone.of:
In short: Zone.of derives a specific zone name from a five-digit postcode by calculating the sum of its digits modulo seven, validating that the input is exactly five digits and raising an IllegalArgumentException with the message "postcode must be exactly five digits" or "postcode must contain only digits" if the format is invalid. [k10, k11, k12]
- Zone.of(<postcode>) returns the zone whose ordinal equals the sum of the digits of <postcode> modulo seven [k1, k2, k3, k4, k5, k6, k7, k8, k9]

Labeler.checkChar:
In short: Labeler.checkChar computes a single uppercase alphabet character from a seven-character body of uppercase letters and digits using a weighted sum modulo 19, validating that the input is exactly seven characters and contains only uppercase letters and digits, raising an IllegalArgumentException with the message "body must be exactly 7 characters" or "body must contain only uppercase letters and digits" if the format is invalid. [k14, k15, k16, k17]
- Labeler.checkChar(<body>) returns the 19-letter alphabet character at index (sum of each character's value times its position's weight) mod 19, where a digit d has value d and an uppercase letter L has value 10+(L-'A'), with weights {7,3,9,7,3,9,7} [k13, k18, k20, k21, k22]
  - e.g. Labeler.checkChar("NO00001") returned 'N'; Labeler.checkChar("EA00001") returned 'C'; Labeler.checkChar("WE12345") returned 'J'; Labeler.checkChar("SU99999") returned 'N'; Labeler.checkChar("VA00042") returned 'N'; Labeler.checkChar("HA00099") returned 'J'; Labeler.checkChar("SO00042") returned 'R' [k13]
  - e.g. Labeler.checkChar("0000000") returned 'A' [k18]
  - e.g. Labeler.checkChar("WE12345") returned 'J' [k20]
  - e.g. Labeler.checkChar("SU99999") returned 'N' [k21]
  - e.g. Labeler.checkChar("NO00001") returned 'N' [k22]

Labeler.next:
In short: Labeler.next generates a label in the format "XX-NNNNN-C" where the zone prefix is the first two letters of the zone derived from the postcode, the number is a running counter starting at 00001 that increments on each successful call, and the check character is computed from the body, while rejecting invalid postcodes with an IllegalArgumentException without incrementing the counter.
- Labeler.next(<postcode>) returns a label whose zone prefix is the first two letters of the zone derived from <postcode>, whose number is 00001, and whose check character is the weighted check of that body [k23, k28, k29, k30, k31, k34]
  - e.g. Labeler.next("10115") returned "EA-00001-C" [k23, k28, k29, k30, k34]
  - e.g. Labeler.next("20095") returned "SO-00001-K" [k31]
- Each subsequent Labeler.next(<postcode>) call on the same instance increments the running number by one [k24]

Labeler.isValid:
In short: Labeler.isValid returns true for a ten-character uppercase label in the format "XX-NNNNN-C" where the zone prefix is known, the middle field consists of five digits, and the trailing check character matches the weighted computation, returning false for any deviation in format, case, or consistency.
