What it is: Shipping-label codes for parcels: a zone from the postcode, a running number, and a check character. [r2]
How it is used: library-style -- exercised inside the same process, by a test that calls it. Exercised here through: Zone.of, Labeler.checkChar, Labeler.next, Labeler.isValid.

Zone.of:
In short: Zone.of maps a five-digit postcode to a zone name. The zone is determined by the sum of the postcode digits modulo seven. The postcode must be exactly five digits, otherwise an IllegalArgumentException is raised.
- Zone.of(<postcode>) returns the zone whose ordinal equals the sum of the digits of <postcode> modulo seven [k1, k2, k3, k4, k5, k6, k7, k8, k9]

  - e.g. Zone.of("01067") returned NORTH [k2]
  - e.g. Zone.of("10115") returned EAST [k3]
  - e.g. Zone.of("20095") returned SOUTH [k4]

Labeler.checkChar:
In short: Labeler.checkChar computes a single check character from a seven-character body. The body must contain only uppercase letters and digits, otherwise an IllegalArgumentException is raised. The result is the 19-letter alphabet character at the index of the weighted sum modulo 19.
- Labeler.checkChar(<body>) returns the 19-letter alphabet character at index (sum of each character's value times its position's weight) mod 19, where a digit d has value d and an uppercase letter L has value 10+(L-'A'), with weights {7,3,9,7,3,9,7} [k13, k18, k20, k21, k22]

Labeler.next:
In short: Labeler.next generates a label with a zone prefix, a running number, and a check character. The running number starts at 00001 and increments by one for each valid call. Invalid postcodes raise an IllegalArgumentException and do not increment the running number.
- Labeler.next(<postcode>) returns a label whose zone prefix is the first two letters of the zone derived from <postcode>, whose number is 00001, and whose check character is the weighted check of that body [k23, k28, k29, k30, k31, k34]
  - e.g. Labeler.next("10115") returned "EA-00001-C" [k23, k28, k29, k30, k34]
  - e.g. Labeler.next("20095") returned "SO-00001-K" [k31]
- Each subsequent Labeler.next(<postcode>) call on the same instance increments the running number by one [k24]
- Labeler.next(<postcode>) raises IllegalArgumentException and consumes no running number when <postcode> is rejected [k26, k32, k33]

Labeler.isValid:
In short: Labeler.isValid verifies that a label is well-formed and consistent. It returns true only if the zone prefix, digits, and check character match the weighted computation. It returns false if the label is malformed, has incorrect dashes, or contains invalid characters. [k35]
