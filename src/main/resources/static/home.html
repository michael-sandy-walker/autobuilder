Direction

A new project

Writes only bootstrap/seed.txt in the new directory, then starts it as a new project.

Or start from an existing specification

Restart clears a project's code and starts a new lineage from its specification, never reading the earlier run. Duplicate makes a new project from a copy of its specification, obligations and settings, and leaves the original as it is.

Import a codebase

Copies the code into the new project's output/ (leaving out .git, build output and IDE folders); the original is only read. Then it is adopted: nothing is cleared, and it waits for a goal.

Or import one already here

Adopt in place works on a project's code where it is. Import a copy makes a new project from a copy of its code -- no goal, no history -- and adopts that; the original is left as it is. Either way the run waits for a goal.

Bring projects together

Starts an empty project, gives it the goal, then brings each project in -- code, goals and criteria; each can take minutes. Differences no intent settles wait for you to decide. The chosen projects are only read.

Finished
