What it is: A tool that reads an acceptance criterion about an HTTP endpoint and a specification stating response statuses for endpoints, extracting values from text. [r2, r3, r4, r5]
How it is used: library-style -- exercised inside the same process, by a test that calls it. Exercised here through: EndpointPaths.declaredIn, EndpointPaths.normalizePath, EndpointPaths.discardedInput, SpecEndpointBehaviourQuery.statedBehaviours, SpecEndpointBehaviourQuery.criteriaFor, BehaviouralCriterionParser.parse, SeedStatusSupport.of.

EndpointPaths.declaredIn:
- When `declaredIn(null)` is called, it returns an empty set [k9, k25]
  - e.g. assertTrue(EndpointPaths.declaredIn(null).isEmpty()); [k9, k25]
- When `declaredIn("no endpoints here")` is called, it returns an empty set [k10, k26]
  - e.g. assertTrue(EndpointPaths.declaredIn("no endpoints here").isEmpty()); [k10]
  - e.g. assertTrue(EndpointPaths.declaredIn("The system returns a list of loans.").isEmpty()); [k26]
- When `declaredIn("GET /Loans")` is called, it returns a set containing the endpoint with verb "GET" and path "/loans" [k11]
- When `declaredIn("GET /")` is called, it returns an empty set [k12]
- When `declaredIn("GET /loans and again GET /loans?memberId=1")` is called, it returns a set of size 1 containing the endpoint with verb "GET" and path "/loans" [k29]
- When `declaredIn("GET /loans?memberId=42")` is called, it returns a set containing the endpoint with verb "GET" and path "/loans" [k30]
- When `declaredIn("GET //loans//details")` is called, it returns a set containing the endpoint with verb "GET" and path "/loans/details" [k31]
- When `declaredIn("GET /books/{id}")` is called, it returns a set containing the endpoint with verb "GET" and path "/books/{}" [k32]
- When `declaredIn("GET /loans/")` is called, it returns a set containing the endpoint with verb "GET" and path "/loans" [k33]
- When `declaredIn("GET /Loans/Details")` is called, it returns a set containing the endpoint with verb "GET" and path "/loans/details" [k34]
- When `declaredIn("GET /")` is called, it returns an empty set [k35]
- When `declaredIn("GET /?memberId=1")` is called, it returns an empty set [k36]
