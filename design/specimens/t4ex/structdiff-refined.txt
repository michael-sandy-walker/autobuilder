What it is: Structural diff of Java sources that parses Java source into a tree of declared elements and compares two versions of a file, reporting which elements were added, removed or changed [r2, r3, r4]
How it is used: library-style -- exercised inside the same process, by a test that calls it. Exercised here through: StructuralDiffNode.isUnchanged, StructuralDiffNode.getType, StructuralDiffNode.getId, ParsedElementBuilder.addChild, StructuralDiffNode.isModified, DiffSummarizer.summarizePlainText, JavaStructureParser.parse, StructuralDiffUtils.flatten, StructuralDiffUtils.filterByType, StructuralDiffUtils.hasChanges, StructuralJavaDiffBuilder.diffJavaFile.
